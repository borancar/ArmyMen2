# The copy protection, and the fact that it is disabled

Generated by `tools/cdchecks.py`. Do not edit.

`FindGameCD` (`0x00426B50`) answers non-zero when the ARMYMEN2 CD is
in a drive. It is called from five places, and each caller tests the
result and branches past a `MessageBoxA` that says the CD is
required.

**5 of the 5** are unconditional in this
executable. The byte at the jump is `EB` (`jmp`)
where a `75` (`jne`) has to have been: same length, so nothing moved,
and the `test` in front of it is left setting flags that nothing
reads. No compiler emits a `test` whose flags are dead followed by an
unconditional jump, so this is a patch and not a build option.

The consequence is that every one of those `MessageBoxA` calls is
unreachable. They still count as import sites, which is why
`docs/boundary.md` has to say whether a site can actually execute
before calling it outstanding work.

| call site | jump | now | retail | restore with |
|---|---|---|---|---|
| `0x0040ee96` | `0x0040ee9d` | `jmp 0x40eef0` | `jne 0x40eef0` | `0x0040ee9d: EB -> 75` |
| `0x0042ed44` | `0x0042ed4b` | `jmp 0x42ed7b` | `jne 0x42ed7b` | `0x0042ed4b: EB -> 75` |
| `0x0042f2a2` | `0x0042f2a9` | `jmp 0x42f2d9` | `jne 0x42f2d9` | `0x0042f2a9: EB -> 75` |
| `0x0044d2fc` | `0x0044d303` | `jmp 0x44d32e` | `jne 0x44d32e` | `0x0044d303: EB -> 75` |
| `0x0044d403` | `0x0044d40a` | `jmp 0x44d431` | `jne 0x44d431` | `0x0044d40a: EB -> 75` |

## Putting it back

Each is a single byte, in place, no relocation:

```
0x0040ee9d  EB -> 75
0x0042ed4b  EB -> 75
0x0042f2a9  EB -> 75
0x0044d303  EB -> 75
0x0044d40a  EB -> 75
```

`src/game/cdcheck.h` carries the same thing as source: the check the
retail build performed, written out behind `#ifdef
AM2_COPY_PROTECTION` so it is recorded and compiles, but is not built
by default -- the port matches the binary it is derived from.

Do not turn it on expecting the game to then demand a CD. All five
call sites are in menu functions that are still the original's code,
so nothing calls the restored check yet and the patched bytes would
keep letting everyone through regardless.

It is also deliberately not built by default for a second reason. The
port is verified by running the original and the reconstruction side
by side and comparing (`tools/ab.sh`); a reconstructed menu function
that demanded a CD where the original's does not would diverge on
every such comparison, for a reason having nothing to do with whether
the reconstruction is correct.
